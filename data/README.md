# data/ — 師楽からの受け渡しデータ置き場

社用PCの師楽からエクスポートしたファイル・スクリーンショットをここにアップロードする。
（GitHubのWeb画面 → このフォルダを開く → Add file → Upload files）

## ファイル名規則

`YYYYMMDD_内容_版数.拡張子`

例:
- `20260715_完成時間割_v23.csv`
- `20260715_自動配置残りコマ_v05.png`
- `20260715_師楽_教員条件設定画面.png`

## 注意（このリポジトリは公開です）

- 教員のフルネーム・連絡先・契約条件などの個人情報は**アップロードしない**
- 迷ったら匿名化（教員名→教科＋番号）するか、Claudeのチャットに直接添付する
  （チャット添付なら公開されない）

アップロードしたら Claude Code のセッションで「data/ に◯◯を置いた」と伝えれば分析が始まります。
詳細は [../shiraku/docs/05_データ受け渡し運用手順.md](../shiraku/docs/05_データ受け渡し運用手順.md) を参照。
