# 師楽 × 時間割作成 支援キット

「師楽」（時間割作成ソフト）を使って本校の時間割を作成するための資料・ツール集です。
師楽そのものは**社用PCのローカル環境**でしか動かせない前提で、
「社用PC ⇔ Claude Code（Web） ⇔ 私用PC」の3拠点で回す運用を想定しています。

## 運用フロー（3拠点モデル）

```
┌──────────────┐  ①エクスポート/入力データ  ┌──────────────────┐
│  社用PC       │ ─────────────────────→ │ Claude Code (Web) │
│  師楽ローカル │    (GitHubアップロード /   │  分析・検証・助言   │
│  作業本体     │     チャット添付)          └────────┬─────────┘
└──────▲───────┘                                    │ ②分析結果を公開
       │                                            ▼
       │ ④助言を反映して師楽を操作      ┌──────────────────────┐
       └──────────────────────────── │ 私用PC（閲覧専用）      │
                                      │ Artifact / GitHub 閲覧 │
                                      └──────────────────────┘
```

- **①渡す**: 師楽の印刷プレビューのスクリーンショット、CSV/Excelエクスポート、
  または手入力の条件一覧を、このリポジトリの `data/` フォルダにアップロード
  （GitHubのWeb画面から「Add file → Upload files」でOK）するか、
  Claude Code のチャットに直接添付する。詳細は [docs/05_データ受け渡し運用手順.md](docs/05_データ受け渡し運用手順.md)。
- **②見る**: Claude が分析結果を Artifact（claude.ai 上の非公開ページ）として公開。
  私用PCから claude.ai にログインすれば閲覧できる。
  ※教員名を含む詳細分析は公開リポジトリではなく Artifact 側に置く。
- **③検証する**: [analyzer.html](analyzer.html) をブラウザで開けば、
  ネット接続なしでも時間割データの機械検証（重複・出勤不可違反・連続コマ等）ができる。
  社用PCにこのファイル1個をコピーして使うことも可能。

## このキットの考え方

1. **まず師楽（高等学校版）というソフトを学び、本校の条件で使いこなす。**
   ※「師楽高等学校」はYE DIGITAL製ソフトの高校版の製品名。デモ版や同梱サンプルデータが
   あればそれで自動配置の挙動を掴んでから、本校データに移る。
2. **師楽に入れる前の「条件の棚卸し」が9割。**
   自動配置が失敗する原因のほとんどは、矛盾した条件・入れ忘れた条件。
   チェックリスト（docs/04）で先に紙上で矛盾を潰す。
3. **機械検証を習慣にする。**
   完成済みの2026年度時間割（23番）にも違反が3件残っていた。
   版が上がるたびに analyzer.html にかけて客観チェックする。
