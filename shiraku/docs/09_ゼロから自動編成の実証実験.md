# ゼロから自動編成の実証実験 — AIの現在地の測定（2026-07-15）

「実務ではなく、AIの力でゼロからどこまで完成に近づけられるかを知りたい」（担当者）への回答。

## 実験設計

- **入力**: v23の「解」は使わず、**条件だけ**を与える
  - コマ定義511グループ（クラス集合・教員集合・週コマ数・連続ブロック要件）
  - クラスの許可枠（基準=コマ数のため枠組みは確定情報）
  - 教員の×グリッド・会議（師楽CSV由来・104/105名検証済み）
  - 教室割当と容量（外／中=4他）、雨天ルール（理想値=同時2授業）、昼ルール（4/5限）、
    1日・連続上限（v23実績をプロキシ）
- **ソルバー**: Google OR-Tools CP-SAT（制約充足＋最適化）。`shiraku/tools/solve_from_zero.py`
- **目標**: 全ハード制約を満たした上で「同日重複」を最小化

## 結果（複合教室修正後の最終版）

| 指標（独立検証） | v23（人手＋師楽・23版） | **AI（ゼロから）** |
|---|---|---|
| 配置完了 | 1,152スロット | 1,152スロット（全数） |
| ハード違反（二重配置・×・会議・クラス枠・教室重複） | 0 | **0** |
| 昼休み消失 | 1件（兼先生・月曜） | **0件** |
| 雨天妥協枠の使用 | 0 | 0（ハード制約化） |
| 同日重複ペナルティ（同一指標・連続設計除く） | 80 | **26** |
| 2単位・同日・非連続 | 7件 | **1件** |
| 所要時間 | 数週間・23版 | **41.1秒（最適解）** |

出力: `AI自動編成_実証実験.csv`（1,427行。実務投入は目的外）

### 実験過程の記録: モデルの穴を監査が発見（実力測定の一部）
初回の解（26.5秒）は自己検証では違反0だったが、独立監査で**複合教室
「中/中」（中1音/美・隔週＝音楽室＋美術室を同時使用）を分解していなかった**穴が発覚し、
中学音楽室の二重使用が2スロット生じていた。構成室への分解を実装して解き直し（41.1秒）、
重複ゼロを再監査で確認。**教訓: ソルバーの「違反0」はモデルの完全性までは保証しない。
独立監査とセットで初めて信頼できる**（人間の校閲工程がAIにも必要という実証）。

## この数字が意味すること（正直な評価）

### AIができたこと
- **「配置」工程は実用水準を超えている**。全制約充足＋品質指標でv23を上回る解を26.5秒で出した
- 同日重複80→25、2単位割れ7→0は「制約が完全にデータ化されていれば機械が強い」ことの実証

### AIができていないこと（この実験がやっていないこと）
1. **設計工程はやっていない**。コマの定義（誰がどのクラスを何コマ持つか・合併/展開の構造・
   連続設計・クラスの枠組み）は**全部v23＝人間の仕事から借りた**。23版の大半はこの設計と
   条件交渉の過程であり、そこはAIの守備範囲外
2. **暗黙の好みは守れていない**。データ化されていない配慮（教科の並び・特定の先生の事情・
   午前午後のバランス等）はこの解に反映されていない。v23の「同日重複80」の中には
   **意図的な選択**も含まれているはずで、単純な優劣比較はフェアではない
3. 上限値はv23実績のプロキシ。個別設定の完全リストではない

### 結論: 現在の実力の正確な位置

**「条件が完全に書き下されていれば、配置はAIが人間より速く・きれいにできる」**
**「条件を書き下す作業（設計・交渉・暗黙知の言語化）は依然として人間の仕事」**

→ 実務での最適な役割分担: 人間が設計と条件確定（Phase 1〜3）、
AIが配置の下書きと検証（Phase 4〜6の支援）、手直しの主導権は人間。

## 第2ラウンド: 構造差分監査による「書かれていないルール」の発見（2026-07-15）

担当者の指摘「4単位が同日3回はないか？ もっと根本的なルールの見落としが不安」を受け、
**v23を仕様書とみなしてAI解との構造差分を総ざらい**した。

### 監査結果
1. **同日3回以上**: v23にもAI解にも存在しない（両方とも最大2回）。
   ただし初版モデルではソフトペナルティ止まりだったため、**同日3回以上をハード禁止に格上げ**
2. **発見された暗黙ルール①: 制度コマの指定枠**。LHR1年がv23の火8→AI解で火5に移動するなど、
   LHR・学活・道徳・総合系の計95クラスコマが「合法だが慣行違反」の位置に動いていた
   （教科×時限ヒストグラムでも学活系が8限帯→昼前に大移動していた）
3. **発見された暗黙ルール②: ピンポイント出勤との連動**。総進一貫総探（金2）が火7に移動
   — これは吉福先生が「金2のためだけに出勤する」設計とセットのコマであり、動かすと
   出勤契約の前提が崩れる。**コマと教員出勤設計の連動は×グリッドだけでは表現しきれない**
4. 放課後補講（9限）はAI解でも正しく9限に残っていた（クラス枠の構造で自動的に守られる）

### 対策と第3版の結果
制度コマ73スロットをv23の枠に**ピン留め**（師楽の「確定」に相当）＋同日3回ハード禁止で再解:

| 指標 | v23 | AI第2版 | **AI第3版（ピン留め）** |
|---|---|---|---|
| ハード違反・教室重複 | 0 | 0 | 0 |
| 制度コマの移動 | — | 95 | **0** |
| 同日3回以上 | 0 | 0 | 0（**ハード保証**） |
| 同日重複ペナルティ | 80 | 26 | 32 |
| 2単位・同日・非連続 | 7 | 1 | 4 |
| 昼休み消失 | 1 | 0 | 0 |
| 求解時間 | — | 41.1秒 | 28.5秒 |

ピン留めで自由度が減った分、同日系の品質は少し悪化（それでもv23の半分以下）。
**制約の追加は品質とのトレードオフ**という関係も定量的に見えた。

### 「見落とし不安」への体系的な答え

未知のルールは「思い出す」のではなく、**このループで掘り出せる**:
```
AI解を作る → v23との構造差分を監査 → 差分の中から「これはダメ」を人間が指摘
→ ルール化（ピン留め/ハード制約）→ 再解 → 差分が「全部OK」になるまで繰り返す
```
1周目で2種類の暗黙ルールが出た。数周で「書かれていないルール集」が完成し、
それ自体が**次の担当者への最高の引き継ぎ資料**になる。
最終判定は常に人間（教務の校閲）— AIの違反0はモデルの範囲でしか意味を持たない。

## 第3ラウンド: 大型コマは「勤務条件から逆算」へ（担当者の設計思想を実装・2026-07-15）

担当者の指摘: 「LHRと総合の位置は合理的なところに行けば問題ない。
**むしろ大型授業なので、勤務条件から逆算して出すべき**」
→ ピン留めを制度固定（道徳・放課後・土曜）だけに絞り、大型コマ（LHR・総合・学活）は
ソルバーに最適位置を選ばせる第4版を実行（90.9秒・最適解）。

### 大型コマの逆算結果（担任団全員の空きが揃う候補枠）

| 大型コマ | クラス/教員 | v23の枠 | AI逆算 | 全員の空きが揃う枠 |
|---|---|---|---|---|
| 特進・総合的な探究 | 5/6 | 火5 | **火5 ←同じ** | 5枠（火のみ） |
| ｽﾎﾟ進・総合的な探究 | 6/6 | 火7 | 火6 | 5枠（火のみ） |
| LHR1年 | 9/11 | 火8 | 火3 | **6枠（火のみ）** |
| LHR2年 | 10/11 | 金7 | **金7 ←同じ** | 6枠（金のみ） |
| LHR3年 | 10/11 | 木7 | 木5 | 6枠（木のみ） |
| 中1学活／総合 | 4/8 | 水4／金7-8 | 水4←同じ／金6-7 | 7枠 |
| 中2学活／総合 | 4/8 | 木1／木7-8 | 木1←同じ／木2-3 | 6枠（木のみ） |
| 中3学活／総合 | 4/8 | 金6／金7-8 | 金8／金6-7 | 7枠（金のみ） |
| 総進一貫1年総合 | 6/9 | 金2 | 火2 | 7枠 |

### この表が示す重要な発見

1. **「LHR1年=火曜」は慣行ではなく勤務条件の必然だった**。担任団11名の空きが揃う枠は
   火曜の6枠しか存在しない。LHR2年=金曜のみ、LHR3年=木曜のみ、も同様。
   第2ラウンドで「慣行違反」と見えた移動（火8→火5等）は、実は**同じ必然の曜日の中での
   時限変え**に過ぎなかった。担当者の設計思想（大型は逆算）がデータで裏付けられた形
2. 4/14の大型コマはAIの逆算がv23と完全一致（人間の配置は逆算的に最適だった）
3. **総進一貫総探を火2に置く選択肢**をAIが提示 — 採用すれば吉福先生の
   「金2ピンポイント出勤」自体が不要になる（契約・本人希望との調整は人間の領域）
4. 品質は全版で最良: **同日重複ペナルティ27・2単位割れ0・同日3回以上0（ハード）・昼消失0**

### ルール集の更新（ループ3周目の成果）
- LHR・総合・学活 = 位置自由（合理性基準）。ただし**候補枠の狭さ自体が本質的制約**
- 制度固定 = 道徳・放課後・土曜のみ
- 同日3回以上 = ハード禁止

## 再現方法

```
pip install ortools
python3 shiraku/tools/solve_from_zero.py
```
入力データを来年度の条件に差し替えれば、来年度版の「配置下書き」も同じ方法で生成できる。
（ただし師楽に読み戻す手段がないため、下書きの使い方は「手差しの参考」まで）
