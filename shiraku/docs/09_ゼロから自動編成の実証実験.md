# ゼロから自動編成の実証実験 — AIの現在地の測定（2026-07-15）

「実務ではなく、AIの力でゼロからどこまで完成に近づけられるかを知りたい」（担当者）への回答。

## 実験設計

- **入力**: v23の「解」は使わず、**条件だけ**を与える
  - コマ定義511グループ（クラス集合・教員集合・週コマ数・連続ブロック要件）
  - クラスの許可枠（基準=コマ数のため枠組みは確定情報）
  - 教員の×グリッド・会議（師楽CSV由来・104/105名検証済み）
  - 教室割当と容量（外／中=4他）、雨天ルール（理想値=同時2授業）、昼ルール（4/5限）、
    1日・連続上限（v23実績をプロキシ）
- **ソルバー**: Google OR-Tools CP-SAT（制約充足＋最適化）。`shiraku/tools/solve_from_zero.py`
- **目標**: 全ハード制約を満たした上で「同日重複」を最小化

| 指標（独立検証） | v23（人手＋師楽・23版） | **AI（ゼロから）** |
|---|---|---|
| 配置完了 | 1,152スロット | 1,152スロット（全数） |
| ハード違反（二重配置・×・会議・クラス枠・教室重複） | 0 | **0** |
| 昼休み消失 | 1件（兼先生・月曜） | **0件** |
| 雨天妥協枠の使用 | 0 | 0（ハード制約化） |

| 所要時間 | 数週間・23版 | **41.1秒（最適解）** |

### 実験過程の記録: モデルの穴を監査が発見（実力測定の一部）
初回の解（26.5秒）は自己検証では違反0だったが、独立監査で**複合教室
「中/中」（中1音/美・隔週＝音楽室＋美術室を同時使用）を分解していなかった**穴が発覚し、
中学音楽室の二重使用が2スロット生じていた。構成室への分解を実装して解き直し（41.1秒）、
重複ゼロを再監査で確認。**教訓: ソルバーの「違反0」はモデルの完全性までは保証しない。
独立監査とセットで初めて信頼できる**（人間の校閲工程がAIにも必要という実証）。

| 教員の同時1コマ | ◎ ハード | |

| 会議 | ◎ ハード | |

## この数字が意味すること（正直な評価）

### AIができたこと
- **「配置」工程は実用水準を超えている**。全制約充足＋品質指標でv23を上回る解を26.5秒で出した
- 同日重複80→25、2単位割れ7→0は「制約が完全にデータ化されていれば機械が強い」ことの実証

### AIができていないこと（この実験がやっていないこと）
1. **設計工程はやっていない**。コマの定義（誰がどのクラスを何コマ持つか・合併/展開の構造・
   連続設計・クラスの枠組み）は**全部v23＝人間の仕事から借りた**。23版の大半はこの設計と
   条件交渉の過程であり、そこはAIの守備範囲外
2. **暗黙の好みは守れていない**。データ化されていない配慮（教科の並び・特定の先生の事情・
   午前午後のバランス等）はこの解に反映されていない。v23の「同日重複80」の中には
   **意図的な選択**も含まれているはずで、単純な優劣比較はフェアではない
3. 上限値はv23実績のプロキシ。個別設定の完全リストではない

### 結論: 現在の実力の正確な位置

**「条件が完全に書き下されていれば、配置はAIが人間より速く・きれいにできる」**
**「条件を書き下す作業（設計・交渉・暗黙知の言語化）は依然として人間の仕事」**

→ 実務での最適な役割分担: 人間が設計と条件確定（Phase 1〜3）、
AIが配置の下書きと検証（Phase 4〜6の支援）、手直しの主導権は人間。
