# 自作時間割ソフト構想（保留中・判断材料の記録）

**現在の方針: 自作は保留し、師楽の習熟を優先する**（2026-07-15 決定）。
本文書は「作れるか？」の技術評価を将来のために記録したもの。

## 結論

作れる。41クラス・1,152コマ・教員108名という規模は、現代の制約ソルバー
（Google OR-Tools の CP-SAT 等）で扱える範囲。学校時間割は組合せ最適化の古典的な適用例。

## 本校が好条件な理由

1. **正解データがある**: 完成時間割23番。自作エンジンが「違反0の解」を出せるか客観的にベンチマークできる
2. **制約の書式が解読済み**: 出勤不可・禁止時限・会議・合併展開のデータ構造は分析済み（docs/01）
3. **3拠点運用と相性が良い**: 重い計算はClaude側（クラウド）、対話的な手直しは社用PCのブラウザ単体ツールで分担できる

## 設計案

```
[A] 手動編成支援ツール（ブラウザ単体HTML・インストール不要・外部送信なし）
    盤面エディタ＋リアルタイム違反チェック＋「このコマが置ける枠」の提示
    ＋確定ロック＋版管理＋CSV/JSON入出力
    → 確実に作れる。今あるデータだけで着手可能

[B] 自動配置エンジン（Claude側で実行）
    教育課程表＋条件ファイル → CP-SATで解を計算 → [A]に読み込んで手直し
    → 前提: 教育課程表・教室制約・担当割データが揃うこと

[C] 帳票・印刷
    市販ソフトが強い領域。当面はExcel出力で足りる
```

## 正直なリスク

- 自動配置の「最後の数％の手詰まり」処理は市販ソフトが長年チューニングしてきた部分。
  ただし師楽自体も「自動作成は完了しきらず残りは手動」が実態（docs/02の体験談）なので同じ土俵
- 帳票・印刷様式の作り込みは地味に工数がかかる

## 再検討のトリガー（こうなったら自作を再検討）

      → 2026-07-15 最終確認: **時間割本体のCSV出力あり**（表示画面のCSVボタン。全体時間割・全先生時間割等5種）。
      名称マスタCSVと合わせてデータ連携は十分成立 → **トリガー①は不成立**。保留継続で問題なし

- [ ] Phase 5（自動配置⇄手直し）で行き詰まり、残りコマの原因分析だけでは前に進めない場合
