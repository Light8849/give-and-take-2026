# データ受け渡し運用手順（社用PC ⇔ Claude ⇔ 私用PC）

## 前提

- 師楽は**社用PCのローカル環境**でのみ動く
- 社用PCから Web（GitHub / claude.ai）へのファイルアップロードは可能
- 私用PCでは閲覧が中心（claude.ai と GitHub にログインできる）
- **このリポジトリは公開（public）** なので、個人名入りの生データを置く場合は注意
  （現状の index.html には教員の略名が既に含まれている。フルネーム・個人情報は置かない）

## ルート1: GitHub 経由（ファイルが残る・推奨）

1. 社用PCで師楽からエクスポート（CSV/Excel）またはスクリーンショットを撮る
2. ブラウザで `github.com/Light8849/give-and-take-2026` を開く
3. `data/` フォルダへ **Add file → Upload files** でアップロード
   - ファイル名規則: `YYYYMMDD_内容_版数.拡張子`
     例: `20260715_完成時間割_v23.csv`、`20260715_自動配置残りコマ_v05.png`
4. Claude Code（Web）のこのセッションで「data/ に◯◯を置いたので分析して」と伝える
5. Claude が分析し、結果を **Artifact（非公開ページ）** に反映
6. 私用PCで claude.ai を開き、Artifact を閲覧

## ルート2: チャット直接添付（手早い・単発向き）

1. claude.ai / Claude Code のチャットにスクショやCSVを直接添付して依頼
2. 結果は同じく Artifact に反映してもらう

## 何を渡すと何ができるか

| 渡すもの | Claude ができること |
|---|---|
| 師楽のエクスポートCSV（時間割全体） | 機械検証（違反検出）、負荷分析、analyzer.html 用データ生成 |
| 自動配置後の「残りコマ」一覧（スクショ可） | ボトルネック条件の特定、緩和案の提案 |
| 教育課程表（クラス×科目×単位数） | 登録コマ数との突合、教科別供給チェック |
| 非常勤の出勤可能日一覧 | 曜日ボトルネック計算、配置可能性の事前判定 |
| 条件洗い出しチェックリスト（docs/04 記入済み） | 矛盾検出、絶対/努力条件の設計レビュー |
| 師楽の画面スクショ（設定画面） | 操作手順の助言、設定の意味の解説、マニュアル化 |
| 師楽のメニュー・設定画面のスクショ（デモ/サンプルデータ含む） | 師楽の機能・データ形式の解読 → 本校用テンプレ作成 |

## スクリーンショットを撮るときのコツ

- 設定画面は**スクロールして全項目**が写るように複数枚
- 一覧系は「印刷プレビュー」があればそれを撮る方が崩れない
- ファイル名に画面名を入れる（例: `20260715_師楽_教員条件設定画面.png`）

## 閲覧側（私用PC）の使い方

- **Artifact**: claude.ai → 自分のアカウント → Artifacts 一覧。
  時間割分析ポータル（このプロジェクトの分析結果とアドバイス置き場）を開く。
  非公開なので URL を知っていても本人以外は見られない。
- **GitHub**: リポジトリの `shiraku/docs/` を直接読む（Markdownは整形表示される）。
- **analyzer.html**: リポジトリからダウンロードしてダブルクリックで開くだけ。
  オフラインで動くので社用PCに持ち込んでもよい。

## セキュリティ上の約束事

1. 公開リポジトリに置いてよいもの: 匿名化済みデータ、集計結果、手順書、ツール
2. Artifact（非公開）に置くもの: 教員名入りの分析、違反の個別指摘
3. どこにも置かないもの: 住所・連絡先・健康情報等の個人情報、給与・契約金額
4. 迷ったら匿名化（教員名→教科＋通し番号）してから渡す
