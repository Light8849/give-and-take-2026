## 2. 確認できた機能（検索スニペットより）

- **時間割作成モードが5つ**ある（各モードの内容はWeb未確認 → 実機で確認したい）
- **基本データのプリセット**: 教科等は学習指導要領準拠で設定済み。学校側は教員・特別教室など個別情報の設定から始める
- **自動作成＋手動調整の併用**が前提の設計
- **「確定」機能**: コマを確定（ロック）すると自動作成でも動かない（FAQ Q03006）
  → 本キットのロードマップPhase 4「骨格固定」は師楽ではこの「確定」で実現する
- **先生別／クラス別コマ設定**画面でコマ数を設定
- **特別教室の設定**に対応
- **ウィザード機能**: データ設定〜時間割作成の手順を画面が案内
- **印刷**: A3/A4・縦横テンプレート、学校独自様式への微調整可
- **ファイルユーティリティ**: データファイルの複写（バックアップ・移動）

## 4. ユーザー体験談から

- 現場教員のブログ（Ver.5時代）: 「現実的な制約下では**自動作成は最後まで完了せず、残りは手動で埋める**のが前提」「UIが古くウィンドウが小さい」
- 市販時間割ソフト全般への評: 「**条件を厳しくすると入りきらず、緩くすると手直しが大量**。機械にある程度埋めさせて人間が動かすのが現実解」
- → どちらも本キットの方針（絶対/努力条件の区別、毎版の機械検証、残りコマの記録）と整合する
