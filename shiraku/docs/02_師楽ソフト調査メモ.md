## 0-3. 実機確認済み事項（2026-07-15 スクショ第3便＋CSV書出サンプル）

### CSV書出の実態（基礎マスタ7種を受領・検証済み）
- 一覧画面のCSVボタンの出力は **名称のみ・Shift_JIS(cp932)・固定幅パディング・CRLF**。属性列は含まれない
- 受領した7ファイル（学年6・先生108・科目名称129・教室13・クラス41・教科11・会議11）は
  **Give&Takeデータと100%一致**（名称の綴りまで完全一致を機械確認済み）
- → 名称マスタの同期・照合には十分。**属性（上限値・担任・会議割当等）はCSVに出ないため、
  属性が要る場合はスクショまたは印字上手の帳票で受け渡す**
- リポジトリ `data/20260715_師楽書出_基礎マスタ/` にUTF-8変換版を保存済み

### 作成条件設定（優先度システムの全貌）
条件は15種で、各条件に**優先度0〜9**を設定。0=無効。画面右に「有効条件: 考慮条件2・絶対条件5」
と集計される（=条件は**絶対条件／考慮条件**の2区分。本キットの「絶対/努力」区分と同じ思想）。

本校の現在の設定値:

| 条件 | 優先度 |
|---|---|
| 同時間に同じ先生の授業をしない | 9 |
| 先生の × に授業をしない | 9 |
| 教室の × に授業をしない | 7 |
| 先生の △ に授業をしない | 6 |
| 先生の一日時間数 | 6 |
| 教室の容量以上に授業をしない | 6 |
| 同曜日に同じコマを設定しない | 5 |
| 同曜日に同じ教科を設定しない | 4 |
| 先生の連続時間数 | 3 |
| 同曜日に同じ科目を設定しない | 2 |
| 連続授業は昼休みをはさまない | 1 |
| クラス側のコマのバラツキ | 1 |
| 非常勤先生の授業は連続させる | 0（無効） |
| ２時間連続授業を2,3時間目に入れない | 0（無効） |
| 同曜日 同クラス 同先生を設定しない | 0（無効） |

追加オプション: 「先生の一日・連続に会議を含める」=OFF ／ **「先生の連続は昼休みで途切る」=ON** ／
「学活・道徳を担任先生の授業に数える」=OFF

**重要**: 「先生の×」と「先生の△」の2段階がある → 教員の時限は「禁止(×)」と「なるべく避ける(△)」を
使い分けられる。「同曜日に同じ科目を設定しない」が優先度2と低いのは、完成時間割に同日重複が
131件あった実態と整合（意図的に緩めてある）。

### 時間割属性グリッド（×の意味）
- 科目等の単位で 月〜土×1〜9限 のグリッドに×を置いて配置禁止を表現
- **黒×=個別に設定した禁止、赤×=学校レベルで使えない時限**（土4限以降など）
- 確認した例では平日5限が全×（＝中学系の項目。中学の昼＝5限を×で表現）
- → **中高の時差昼休みは「時限×」で運用**している

### 普通科目情報設定（コマ定義の構造）
- 列: 科目名／略号／教科名／**先生名（複数行=複数教員）**／教室名／クラス数／連続数／単位数／科目属性／選択(●)
- **「外／中」教室の正体が判明**: ◆柔道/弓道（総・特)・◆体育/弓道(ｽﾎﾟ)1 の教室が「外／中」
  → **「外／中」＝体育系の共用施設プール（同時数4）**。屋外／屋内の集約と推定。
  逆算した「体育同時最大3」は上限4の範囲内で整合
- ◇土曜1〜3限: 連続数3（3コマ連続ブロック）・クラス数27・担当4名 — 分析と一致
- LHRは学年単位で担任団をまとめて登録（LHR1年=9クラス・教員11名）
- 選択●フラグで選択科目を区別

### コマ間属性設定
- クラス/科目/先生 ⇔ クラス/科目/先生 のペア関係を定義する画面。**本校は未使用（空）**

### 助言機能の出力例
- コマを選ぶと「同じ曜日に同じコマがあります。（3限目/5限目）」
  「同じ曜日に同じ科目があります。」「同じ曜日に同じ教科があります。」のように、
  **作成条件（優先度5/2/4のトリオ）に抵触する箇所を文章で指摘**する
- → 考慮条件は「ブロックせず助言として出る」ことを確認。手直し時の品質チェッカーとして機能

### クラス属性「※」の意味が判明（過去の記述を訂正）
- クラス情報設定の属性列: **「※」=そのクラスに個別の時間割属性（×グリッド）が設定済み、「・」=未設定**
- 本校では **1-1〜1-4だけが「・」**（週38コマのフル稼働クラスで個別×が不要）、他の37クラスは「※」
- クラスの×グリッド例: 平日4限×（高校の昼）＋9限×＋8限の一部×＋土4限以降が赤×（学校レベル）
- **クラスの週コマ数（38/37/36/32/30）は、この×グリッドの空き枠数で決まっている**
- ×印は黒/青/赤の3色を確認（赤=学校レベル不可。黒と青の違いは凡例未確認 — 編集状態の差か由来の差）
- ※第2便時点の「1-5にのみ※」という記述は画面の見切れによる誤読だった。上記が正しい

  （＝版管理は師楽内でも可能）。Web FAQの「保存しないと消える」は盤面側の話

```
時間割保存 → 自動作成・差替え → 最適化 ⇄ 自動差替え（交互に繰り返すと効果的）
→ 手差替え（赤・黄コマが残った場合）→ 時間割保存
```
→ ロードマップPhase 5の「自動配置⇄手直し」の実装がこれ。**「最適化」と「自動差替え」を交互に**が公式のコツ

### 読込/書出ボタンの正体

### 検証結果（2026年度データ・jdataとの突合）
- コマ構造: **1,427件が完全一致**、科目名の整合も100%
- 教員の×グリッド: **104/105名が完全一致**
- 教室: 239コマに教室が付く。**リンクス＝情報科の教室（PC室）と判明**（用途の謎解決）

- **△（回避）はCSV出力に1つも現れない** → 本校は×のみで運用している可能性が高い
- 既知の限界: 合併・展開コマの教員結合が一部不完全（377コマは科目名グループで補完）。
  名称の切り詰め（英語ｺﾐｭ等）は前方一致で復元するが同系列科目は曖昧が残る

### 重大な発見: 「違反3件」の再解釈
1. **吉武・木1限**: 現行師楽データに木1の×は**存在しない**（唯一のグリッド差分）
   → Give&Take側の古い/独自の情報。完成時間割の違反ではない
2. **吉福・金曜**: 師楽上は**金2限だけ×を外し残り全部×**という設計
   → 合併総探のためのピンポイント出勤。違反ではなく意図した配置。
   Give&Takeが休みを「曜日単位」でしか持てないため違反に見えていた
3. 昼休み消失（兼先生・月曜）のみ実質的な注意点として残る（師楽の条件としては未設定の領域）

**教訓: 検証の正は師楽CSV**。Give&Takeのデータモデル（曜日単位のoff）は師楽の時限単位×より粗い。
今後の版チェックは「全体時間割.CSV＋全先生時間割.CSV → 変換 → analyzer」の経路で行う。
