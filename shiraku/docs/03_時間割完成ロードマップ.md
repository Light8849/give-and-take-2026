# 時間割完成ロードマップ（準備 → 完成 → 運用）

本校（週6日制・中高一貫・41クラス・教員108名）の規模を前提にした、年度時間割完成までの道のりと手順。
師楽での作業フェーズに対応させてある。日付は一般的な私立中高のモデル（本校の実日程に合わせて調整すること）。

## 全体像

```
Phase 0  操作習得（師楽高等学校＝ソフトの機能棚卸し）  …… いつでも / 今
Phase 1  条件の棚卸し（紙上・Excel上）                …… 12月〜1月
Phase 2  マスタ入力（教員・教科・クラス・教室）        …… 1月〜2月
Phase 3  コマ（授業）登録と条件入力                    …… 2月
Phase 4  骨格固定（合併・展開・非常勤・会議）          …… 2月下旬〜3月
Phase 5  自動配置 → 手直しの反復                      …… 3月
Phase 6  機械検証・関係者校閲・確定                    …… 3月下旬
Phase 7  年度内運用（授業変更 = Give&Take、次年度への記録） …… 通年
```

## Phase 1: 条件の棚卸し（最重要・紙上で行う）

**目的**: 自動配置失敗の原因の大半は矛盾条件。入力前に紙上で潰す。

- [ ] `docs/04_条件洗い出しチェックリスト.md` を教務内で回覧・記入
- [ ] 教育課程表（各クラスの科目×単位数）を確定させる
- [ ] 非常勤の契約（出勤可能曜日・時限）を確定させる ← **ここが遅れると全部遅れる**
- [ ] 常勤の研究日・分掌・会議体の曜日時限を確定させる
- [ ] 合併・展開授業の設計（どのクラス束で・何展開・担当は誰か）を確定させる
- [ ] 特別教室（体育館・理科室・音楽室・PC室等）の同時使用上限を確認する
- [ ] 条件を「**絶対条件**」と「**努力条件**」に仕分ける

**チェックポイント（Claudeに検証依頼できる）**:
教科ごとに「必要コマ数 ≦ 担当者の供給可能コマ数」か。
例: ある曜日に研究日が集中している教科は、その曜日の必要コマ数を賄えるか。

## Phase 2: マスタ入力

- [ ] 教員マスタ（108名: 氏名・教科・常勤/非常勤・担任）
      ※校内マニュアル2020の知見: **先にExcelで教職員名簿を作ってから転記**。会議は6つまで
- [ ] クラスマスタ（41クラス: 中学4×3、高校9/10/10、コース属性）
      ※略号は半角3文字まで（10組は「110」方式）。コース別の×（7限・土曜等）はクラス属性で
- [ ] 時程マスタ（月〜金8限＋土3限。**中高の昼休み時差は時限×で表現**: 高校=4限×、中学=5限×）
- [ ] 教室マスタ（ボトルネック教室のみ: 芸術・調理・オンライン英会話・体育集約「外／中」）
- [ ] 科目名称の設計（教育課程表から。**教科ごとに3学年一気に／単位数違いは別名で分ける／
      担当分割も別科目方式（国総古典1方式）／略号2.5文字**）
- [ ] 入力後、CSVボタンで名称一覧を書出して Claude に渡す → 転記ミス検査（綴り照合は機械化済み）

## Phase 3: コマ登録と条件入力

- [ ] 教育課程表どおりに各クラスの授業コマを登録（合併・展開は束で定義）
- [ ] 教員の出勤不可・禁止時限を入力（94名分の研究日、107名分の禁止時限）
- [ ] 会議・分掌ブロック（105名分）を入力
- [ ] 「1日の最大コマ数」「連続コマ上限」等のポリシー条件を設定
- [ ] **登録コマ数の突合**: クラス週コマ数の合計 = 登録コマ総数か（エクスポートして機械検証）

## Phase 4: 骨格固定（自動配置の前にやる）

置く順番の原則 = **自由度が低いものから**。
本校の実証済み先置きリスト（docs/04 G1・担当者確認済み）:

1. ◇土曜プログラム（27クラス合同・担当4名）等の全校固定枠
2. 拡大選択A/B（人数が多い）
3. 体育の◆ブロック（「外／中」同時4の場所制約）
4. 中学英語C（4人同時授業）
5. 家庭科（調理室1室の場所制約）
6. 非常勤の授業（出勤日が動かせない）・会議枠

- [ ] ここまでを手差しで並べ、コマ確定の「部分確定」でロックして自動配置の対象から外す

## Phase 5: 自動配置 → 手直しの反復

- [ ] 自動配置を実行。**残ったコマ（配置不能）のリストを必ず記録**（スクショ→Claudeへ）
- [ ] 残りコマの原因分析: どの条件がボトルネックか（Claudeが分析を手伝う）
- [ ] 対処の優先順: ①努力条件を緩める → ②担当の入れ替え → ③絶対条件の再交渉
- [ ] **版番号を付けて保存**（前年度は23版。各版で「何を変えたか」を1行メモ）
- [ ] 版ごとにエクスポート → `analyzer.html` で機械検証

## Phase 6: 検証・校閲・確定

- [ ] `analyzer.html` フルチェック: 二重配置・出勤不可違反・禁止時限違反・会議重複・
      昼休み消失（中4限×高5限）・連続5コマ以上・日7コマ以上
- [ ] 教科主任校閲（教科内の並び・実習の連続性など機械で見えない質の確認）
- [ ] 非常勤本人への確認（契約と実配置の突合）
- [ ] 担任のLHR・学年会の整合
- [ ] 印刷物・配布データの作成

## Phase 7: 年度内運用と「来年度への貯金」

- [ ] 日々の授業変更は Give&Take ツールで運用（本リポジトリの index.html）
- [ ] 授業変更（Give&Take）は教員都合の交換であり、**時間割の質の指標にはしない**（担当者確認済み）
- [ ] 年度末に「今年の反省 → 来年の初期条件リスト」を Claude と一緒に整理

## 師楽（Ver.10）の実画面との対応表

実機確認（docs/02 第0章）で判明した、本ロードマップと師楽の画面・用語の対応:

| ロードマップ | 師楽の画面・操作 |
|---|---|
| Phase 2 マスタ入力 | 「基礎」ツリー（科目名称〜選択群情報設定。多くが「分担可能」） |
| Phase 3 コマ登録 | 普通科目情報設定（種別=連続/選択/共同、教室・複数教員の紐付け）＋先生別/クラス別コマ設定 |
| Phase 3 条件入力 | 時間割属性グリッドの×/△（黒×=個別禁止、赤×=学校不可）＋先生情報設定の連続/1日/持ち（個別上書き可） |
| Phase 3 ポリシー条件 | 作成条件設定（15条件×優先度0〜9、絶対/考慮の2区分） |
| Phase 4 骨格固定 | 手差替盤面で配置 → コマ確定の**「部分確定」** |
| Phase 5 自動配置⇄手直し | 「時間割作成」＝[手差替]盤面（▶自動実行、**助言機能ON**、残数列で未配置を追跡）。公式のコツ: **「最適化」と「自動差替え」を交互に繰り返す** → 残った赤(絶対違反)・黄(考慮違反)コマを手差替え |
| Phase 5 版管理 | 時間割盤面の手動保存（基礎・コマは自動保存）。**SRKファイル名に作業内容を書く現行運用を継続**（例:「中高体育固定.SRK」） |
| 隔週授業 | 対象「1週目/2週目」の2週制盤面 |
| Phase 6 検証 | コマチェック＋本キットの analyzer.html（外部検証） |

## 今年の目標設定（担当者ヒアリングを受けて改訂）

**版数は目標にしない。** 23版は「手差し固定→自動→最適化の反復」という正常な工程の記録であり、
減らすこと自体に意味はない（担当者確認済み）。目標は品質指標に置く:

1. **絶対条件違反 0 で確定**（2026年度版は3件残存: 禁止時限1・出勤不可1・昼休み消失1）
2. **「2単位・同日・非連続」の削減**（2026年度: 7件。2年選択ブロックに集中）
3. 毎版 analyzer.html で機械検証し、上記2指標を版ごとに記録する
