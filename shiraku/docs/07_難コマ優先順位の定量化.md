# 難コマ優先順位の定量化（勘の裏付けと補正）

担当者の要望「条件の厳しさの順位は勘で決めている。Claudeに判断してほしい」への回答。
2026年度完成データから**全511科目グループの配置難易度**を機械計算した。

## 計算方法

各科目グループ（pcode単位）について:

```
候補枠数 = 関係クラス全部の使用可能枠 ∩ 担当教員全員の空き枠（研究日・禁止時限・会議を除外）
余裕　　 = 候補枠数 − 必要コマ数（週あたり）
```

- 本校はクラスの基準＝コマ数が一致（空き枠ゼロ運用）なので、クラスの使用可能枠は
  現在の使用枠そのものとして正確に逆算できる
- **余裕が小さいほど厳しい**。余裕0なら置き方がほぼ一意＝真っ先に固定すべきコマ

### この指標の限界（正直な注記）

1. 他のコマとの競合を無視した楽観値 → **絶対値ではなく順位として読む**こと
2. **連続2時間の要件は未考慮**（家庭基礎などは候補枠より実際は厳しい: 候補9枠でも隣接ペアは3〜4組）
3. **教室の容量（外／中=同時4、調理=1等）は未考慮**（体育・家庭科は表の数字より実際は厳しい）
4. 選択群として同時に動くブロックの連動も未考慮
→ 2〜4はいずれも「実際はもっと厳しい」方向のバイアス。順位の上方修正要因として脚注に付記

## 勘との突合

**勘と一致（裏付けが取れたもの）**:
- **拡大選択A/B が全校で1・2位**（余裕1）。勘のとおり最難関
- ◇土曜・総合的な探究ブロック（特進/スポ進/中学）も上位 = 合同系はやはり厳しい
- 中学英語C系も上位（10位）

**勘に無かった「隠れ難コマ」（データが見つけたもの）**:
- **中学理科5（中学3-3担当分）が4位** — 教員1名・週5コマに対し候補12枠。担当者の
  禁止時限・会議が重い。この人のコマは早めに置かないと後で詰む
- **英語ｺﾐｭⅢ4の3-9/3-10（8-9位）、言語文化3の1-8/1-9（14-15位）** — 単独クラスでも
  担当者の空きが薄い。スポ進系クラス×特定教員の組合せ
- 3年選数C/文探2（5位）

**勘より緩く見えるもの（ただし注記あり）**:
- 体育ブロックは教員・クラスの枠だけ見ると余裕13前後。体育の本当の厳しさは
  **「外／中」＝共有資源の奪い合い**（同時4）にあり、この指標の外。
  → 体育を先に置く現行手順は**共有資源を先に確定させる**という意味で合理的。変更不要

## 実際の作業順（SRK版履歴＝23版の工程記録）との比較

版名から読み取れる実際の順: 体育(中高)→LHR/総合→教員縛り(草山・菅原)→中学芸術/技家→
中ALT→水8化学→中学学年ブロック→特進→中学理科→スポーツ→音美書→個別教員(木村・熊田)→
3年選択(12組/34組)→高3→高2→全固定→微修正(23版)

- おおむね「共有資源（場所）→合同ブロック→個別の縛り→学年」の順で、定量ランキングと整合
- **1点だけ検討材料**: 最難関の拡大選択（3年選択）は16版目と後半に固定されている。
  2年選択の「同日・非連続」7件（docs/04 G3）は選択ブロックの後半配置と関係する可能性がある。
  来年度、**拡大選択と2年選択ブロックをもう1段早く置く**実験の価値はある
  （ただし体育より先にすべきかは場所の空き次第。並べ替えは1ブロックずつ試すのが安全）

## 来年度への使い方

1. 科目調査・担当が確定した時点で、来年度の条件でこのランキングを再計算（Claudeに依頼）
2. 出てきた**余裕の小さい順**＝手差し固定の順番の初期案とする（勘の代わりの土台）
3. 共有資源（外／中・調理・音美書・オンライン英会話）は余裕値に現れないため、
   従来どおり体育系を先頭に置く
4. 「隠れ難コマ」（特定教員×特定クラスで余裕が薄いもの）を勘のリストに追加する
