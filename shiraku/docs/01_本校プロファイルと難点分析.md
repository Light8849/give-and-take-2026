# 本校プロファイルと時間割作成上の難点

2026年度 完成時間割（第23版）のデータ（Give&Take ツール埋め込みJSON、のべ1,427クラスコマ／実授業スロット1,152）を機械分析して判明した、本校の構造と難点の整理。
※個別の教員名を含む詳細（違反箇所の特定など）は、公開リポジトリには載せず Artifact 側のレポートに記載する。

## 2. 本校特有の構造的な難点（重要度順）

### ★★★ (1) 条件密度が異常に高い
- **出勤不可曜日（研究日等）: 94名**に設定。月29・火26・水27・木17・金13と**週前半に集中**。
- **禁止時限: 107名・計1,931スロット**。1人あたり平均18スロットが最初から使えない。
- **会議・分掌の時間確保: 105名**に設定。
- → 教員1人の「使える枠」は理論上43コマ（5×8＋土3）だが、実際は平均でその半分程度。
  自動配置の探索空間が非常に狭く、**条件を1つ増やすだけで解が消えることがある**。

### ★★★ (2) 中高兼務者 28名
- 中学と高校の両方で授業を持つ教員が28名。中高で時程（チャイム）がずれる場合、
  移動時間・時限の対応関係を師楽上でどう表現するかが最大の論点になる。

### ★★★ (3) 昼休みの時差構造
- データ上、**高校クラスは4限枠に授業ゼロ、中学クラスは5限枠に授業ゼロ**。
  つまり高校の昼＝4限枠、中学の昼＝5限枠として運用されている（食堂等の分散利用と推定）。
- 中高兼務者が「中学4限→高校5限」と連続すると**昼休みが消える**。
  完成時間割でも1名・週1日でこれが発生している。→ 検証ツールで常時チェックすべき項目。

### ★★ (4) 学年横断の合併・展開授業
- 複数クラス合併の授業スロットが383（うち複数教員の展開・TTが443スロット、最大11名同時）。
- 代表例:
  - 土曜1〜3限: **27クラス合同の外国語プログラム**（担当4名）
  - 高3「拡大選択A/B」: 6クラス束の選択ブロック
  - 各学年「総合的な探究」: コース単位で2〜6クラス合併
  - 「合同体育」、放課後の第2外国語（仏/中）
- 合併授業は関係クラス全部の時間割を同時に固定するため、**最初に置く**必要がある。

### ★★ (5) 非常勤23名の出勤日調整
- 非常勤の平均勤務不可日は週1.6日。非常勤の担当コマは平均14.1と常勤並みに多く、
  **非常勤の contracts（出勤日）が確定しないと骨格が組めない**。

### ★ (6) 土曜の使い方
- 土曜に授業があるのは4名のみ（外国語プログラム）。大半の教員は土曜が会議枠。
- 平日への負荷集中の一因。土曜をどう使うかは毎年度の経営判断事項。

## 3. 完成時間割（第23版）の検証結果 — 【2026-07-15 再解釈: ほぼクリーンと判明】

**当初「違反3件」と報告したが、師楽の時間割CSV（現行データ）との突合で再解釈された。**
完成時間割は師楽の条件上ほぼクリーン。以下は経緯の記録:

機械検証で以下を検出（詳細は Artifact 版レポート参照）:

1. ~~出勤不可曜日に授業が1件~~ → ✅**違反ではなかった**。師楽上は「金2限だけ×を外し
   残り全て×」の設計＝合併総探のためのピンポイント出勤。Give&Takeが休みを曜日単位で
   しか持てないため違反に見えた（docs/02 第0-7章）
2. ~~禁止時限に授業が1件（家庭科）~~ → ✅**現行師楽データに該当の×は存在しない**
   （×グリッド104/105名一致の唯一の差分）。Give&Take側の古い/運用都合の情報と判明
3. 1日7コマの教員日が4件、5連続コマ（放課後含む）が1件
   ※後日、師楽の先生情報設定で「1日の上限」は教員ごとに個別上書きされていることが判明
   （江藤・中島・草山=1日7許可等）。**7コマ日の大半は許可済み設定**であり違反ではない。
   個別上限との突合が検証の正しい形（docs/02 第0-2章参照）
4. 放課後補講が「9限」として1件登録されている（仕様通りか要確認）

実質的に残る注意点は **昼休み消失（中高兼務者が中学4限＋高校5限に連続）1件** と 9限登録の確認のみ。

→ 教訓は2つ。**①完成時間割は師楽の条件上ほぼクリーンだった**（担当者の仕事の質の裏付け）。
**②検証はデータの鮮度が命** — Give&Take側のデータは運用に合わせて動くため、
版チェックは師楽の時間割CSV（全体＋全先生）を正として `analyzer.html`／変換ツールで行う。

## 4. 施設の実効キャパシティ（完成時間割からの逆算）

データに専用の「教室」フィールドは無いが、**施設情報は授業名と同時実施パターンに符号化されている**。
授業名から確認できる施設: 弓道場・柔道場（`◆体育/弓道(ｽﾎﾟ)`、`◆柔道/弓道`）、教室実施の体育（`合同体育(教室)`）、
オンライン英会話。`◆`印は施設共有前提の合同体育ブロック（例: `◆体育3ｺﾏ3人2ｸﾗｽ`＝2クラス束・教員3名）。

完成時間割で同時に走っている授業数の最大値 ＝ 事実上の施設キャパ（要・教務確認）:

| 施設系統 | 同時実施の分布 | 実効上限 | 推定される内訳 |
|---|---|---|---|
| 保健体育（実技） | 1件×12枠、2件×22枠、3件×1枠 | **3** | 体育館＋武道/弓道場＋グラウンド等 |
| 芸術（音・美・書） | 1件×15枠、2件×13枠、3件×3枠 | **3** | 音楽室・美術室・書道室 各1 |
| 家庭 | 1件×26枠、2件×3枠 | **2** | 調理室＋被服室？ |
| 情報 | 1件×14枠 | **1** | PC教室1室 |

→ 時間割作成時は「体育系同時3まで・芸術同時3まで・家庭2・情報1」が破ってはいけない暗黙の上限として
機能していたと推定できる。次年度もこの上限で良いかを教務・各科に確認して docs/04 のE表に転記する。

**【裏取り済み・2026-07-15】** 師楽の教室情報設定（13室）を実機確認。
芸術は高校3室（音・書・美）＋中学2室（音・美）で逆算値と整合。調理1室。
オンライン英会話は高1・中1〜中3の学年別4室＋バーチャル留学1。
**体育施設は「外／中」という集約教室（同時数4）で管理**されていた
（◆柔道/弓道・◆体育/弓道の教室欄が「外／中」。屋外／屋内の施設プールと推定）。
逆算した「体育同時最大3」は上限4の範囲内で整合。個別の体育館・武道場という粒度では
持たず、**集約1枠＋◆合同コマ設計の併用**で解いている。詳細は docs/02 第0-2・0-3章。

あわせて教員データの `meetings` フィールドから**会議体カタログ**も判明:
校務運営(18名)・1〜3学年会(15〜16名)・中1〜中3学年(各9名)・国語科(5名)・管理職会(4名)・運営前半(1名)。
※教科会として登録があるのは国語科のみ。他教科の教科会を時間割条件にしていない理由は要確認。

この分析は「完成した時間割」から逆算できる層だけを見ている。完成品には**結果**しか写っておらず、
**理由**が写っていない。未把握の層と、それを見えるようにするための入手物:

| 展開の内部構造 | 習熟度展開のグループ構成、拡大選択A/Bの中身の科目群 | 選択科目一覧 |
| 年間レベル | 行事・考査・短縮授業・隔週/半期科目・年間時数管理 | 年間行事予定表 |

## 6. この分析が示す「時間割作成の勝ち筋」

1. **確定順序を守る**: 教育課程表 → 非常勤契約・研究日 → 合併/展開ブロック → 会議・分掌 → 一般コマ。
2. **合併授業と土曜プログラムを最初に固定**（動かせる自由度が最も低いため）。
3. **条件は「絶対」と「なるべく」を分けて師楽に入力**（全部「絶対」にすると解がなくなる）。
4. **毎版の機械検証**: 出勤不可・禁止時限・昼休み消失・連続コマ・日7コマ超を自動チェック。
5. **難コマの先置きリストを維持する**: 本校の実証済み手順は「厳しい条件（拡大選択・体育・
   中学英語C・家庭科）を手差しで並べて固定→全体を自動で回して最適化を反復」。
   版の積み重ねは正常な工程であり、版数削減は目標にしない（docs/04 G表参照）。
